🌸 Lily Self-Care - Holistic Wellness Platform
Overview
Lily Self-Care is a responsive wellness platform designed to promote mindfulness, healthy living, and emotional well-being. The site features a daily self-care tracker, wellness services, testimonials, and an FAQ section to guide users on their self-care journey.

Color System
Primary Color: #da519a (Soft Pink) - Creates a warm, inviting atmosphere that aligns with self-care and femininity.

Secondary Color: #080808 (Dark Background) - Provides contrast and makes content pop while reducing eye strain.

Accent Color: #2ecc71 (Vibrant Green) - Used for interactive elements to symbolize growth and renewal.
