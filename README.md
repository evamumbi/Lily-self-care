# 🌸 Lily Self-Care - Holistic Wellness Platform

## 🧘 Overview
**Lily Self-Care** is a responsive wellness platform designed to promote mindfulness, healthy living, and emotional well-being. The site features a daily self-care tracker, wellness services, testimonials, and an FAQ section to guide users on their self-care journey.

---

## 🎨 Color System

- **Primary Color: `#da519a` (Soft Pink)**  
  Creates a warm, inviting atmosphere that aligns with self-care and femininity.

- **Secondary Color: `#080808` (Dark Background)**  
  Provides contrast and makes content pop while reducing eye strain.

- **Accent Color: `#2ecc71` (Vibrant Green)**  
  Used for interactive elements to symbolize growth, healing, and renewal.

These colors were tested with [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) and meet WCAG AA standards for accessibility.

---

## 📱 Breakpoint Logic

- **SM (Small: 0–600px)**  
  - Cards stack vertically in a single column  
  - Navigation collapses into a minimal mobile-friendly menu  
  - Fonts and touch targets increase for better usability

- **MD (Medium: 601–1024px)**  
  - Two-column layout  
  - Adjusted spacing and font sizes for tablet viewing  
  - Navigation simplified and centered

- **LG (Large: 1025px and above)**  
  - Follows the original mockup layout in terms of card size, spacing, and orientation  
  - Fully responsive multi-column grid layout  
  - Expanded nav and full layout styling

---

## ✨ Creative Divergence

While the large screen layout mirrors the mockup's structure (in terms of card size, spacing, and orientation), I introduced original creative elements, including:

- 🌿 Rebranded the theme to **“Lily Self-Care”**, a calming and feminine wellness identity  
- 🎨 Soft pinks, deep contrasts, and vibrant greens for a warm, relaxing aesthetic  
- 🧘‍♀️ Custom content: self-care tips, daily tracker, testimonials, and themed visuals  
- 📱 Thoughtfully designed mobile/tablet layouts for an optimal experience on all devices
